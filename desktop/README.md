# StudyFlow 学程桌面

> **仅供学习用途，严禁用于刷课。** 不得用于代学、代考、伪造学习记录或绕过本人验证。

Windows Qt桌面支持独立启动和连接已有MCP服务。便携包完整解压后双击 `StudyFlow.exe`；源码安装后执行 `python desktop/app.py`。默认启动本地后端，`--preview-only` 仅预览界面。连接现有账号时使用 `start_desktop_console`，配对信息经进程管道传递。

- 账号：添加账号负责录入，已有账号使用一个启动/关闭状态按钮；活动考试和未知提交保留关闭保护。
- 课程：登录后自动读取，勾选并排序后启动队列。相同或已覆盖的队列复用，已暂停队列接续；冲突不会覆盖原队列。
- 进度：每2秒读取实际状态和媒体采样，显示当前视频序号与各视频独立完成标记；未知数量不计为零。
- 试卷：整卷预览后返回，10题一组、最多3组并行处理，模型先判断，仅不确定题联网复核；已确定答案独立保留，正常填写并暂存，最后整卷回读。
- 衔接：人工进入考试或完成验证后，自动识别唯一匹配的新试卷标签，接续本次操作。
- 提交：默认关闭自动交卷。明确授权后仍需整卷一致及身份、锁定等检查；未知结果只读核验，不重放提交。
- 模型：选择服务商、地址和可用模型，保留用户选择的推理强度；请求不设置输出上限，使用服务端默认值。密钥仅保留在本次会话。
- 邮件：共享发件人，每账号收件邮箱和通知间隔独立配置，1–1440分钟、默认60分钟。SMTP接受不等于确认送达。

关闭桌面不关闭共享MCP及账号浏览器。本人验证由本人完成。详见[教程与截图](../docs/使用教程.md)、[故障处理与回归](../docs/故障处理与回归.md)。

测试：在本目录运行 `python -m pytest`。截图由 `scripts/render_screenshots.py` 使用虚构数据渲染，不连接平台。

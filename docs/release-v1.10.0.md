# StudyFlow v1.10.0

**仅供学习用途，严禁用于刷课。** 请遵守课程要求和平台规则；不得用于代学、代考、伪造进度或绕过本人验证。GPL-3.0-only，第三方组件保留原许可。

当前为待发布修改：本轮按要求暂停打包，继续故障锁审查。旧构建不代表本次修复，不作为本轮发布产物。

- 保留 Qt 桌面，将模型调用、任务执行与自动恢复移至独立后台；关闭及重连桌面保留任务。
- 新增学习总览、当前章节与多视频进度、账号状态和服务状态；深蓝侧栏与原创书页图标统一用于窗口、托盘和 EXE。
- 账号页按“添加账号 → 选择课程 → 开始学习”组织，连接状态与学习状态分开说明；诊断收进高级工具，暂停/继续合并。
- 服务商与模型人工选择、明确应用；模型列表不自动选首项，密钥仅在后台会话内存保存。
- 网页播放器事件同步播放时间，正常播放不再每两秒主动采样；事件中断时低频检查，旧视频事件隔离。
- 桌面使用独立事件流即时刷新播放位置，数字跟随网页，进度条平滑过渡；旧状态快照不会覆盖新事件。
- 同账号任务去重、不同账号独立；保留多视频、未知提交只读回查、二维码通知等已有恢复流程。
- 完成后的陈旧等待状态不再重复触发处理；端口占用提供可见诊断。
- 修复已判对弹题重现而遗漏接续；每次重复弹题仍要求本次明确回执，结果未知时保留现场。
- 区分题目暂停、本人验证、视频完成核验和真实同步延迟；切换任务时清除过期进度，事件断流可有界重挂监听。
- 桌面断开及时结束原事件流；慢账号不会阻塞其他账号的实时进度。
- 弹题按题目等待状态处理；明确评分迟到时，核验原回执后自动接续，避免保留过期的超时锁。
- 修复提交前选项读取的页面更新竞争；仅确认尚未提交、原操作结束且题目一致时，释放遗留计划并重新审阅一次。
- 原操作仍执行、只读探测迟到或平台待判分时持续跟进核验；不重交未知提交。顶部和总览统一运行账号计数。
- 迟到的测验评分回读也会登记到成绩和邮件汇总，避免已确认成绩遗漏。
- 显示题目读取、材料读取、模型判断、检索复核、提交回读和恢复播放的阶段、选项及耗时；依据待补充时明确显示尚未提交，避免伪装成持续运行。
- 修复热更新时事件回调和已选择模型对象保留旧方法的问题；模型配置、调用计数及浏览器会话保留。
- 课程题遇到不确定判断时复用有界检索，再由模型给出标注推断依据的最佳判断；搜索不可用不会取消同份题目中已经确定的答案，不编造检索来源。
- 队列只读检查超时单独记录来源，避免旧的已完成测验超时误拦恢复；跨账号、未知提交、未确认成绩仍各自保留约束。
- 故障去重按实际恢复周期释放；单账号调度失败、线程启动失败和本地检查点写入错误不会锁住其他账号。
- 模型瞬时网络错误、恢复时页面加载和通信错误有界自动重试；迟到评分探测保留原回执，健康控制线程也能回读尚未判分的提交。
- 未启动账号可从考试入口直接启动工作区并接续所选课程；查询考试进度不会隐式启动课程队列，已完成账号重新打开浏览器不再重扫历史课程。
- 已确定答案与不确定题检索解耦；单题审阅格式异常单独修复，同批有效结果继续暂存。保留逐题回读及未知写入保护。
- 故障编号按每次实际超时生成并传至桌面；旧版已消费探测在原线程空闲、没有未知提交或活动考试时可作一次新的只读核验。
- 热加载同步审阅格式依赖和账号启动入口，保留现有浏览器、账号状态、模型配置及调用计数。
- 最后一题保存后等待完整预览内容就绪；工作进程返回异常时先只读核验，不重复保存。已经完整回读的试卷再次执行时，只核验完整预览，不返回末题重复写入。

账号操作反馈按当前账号隔离；恢复正常播放后撤下旧故障提示，历史事件仍可查询。

# v1.9.3

仅供学习用途，严禁用于刷课。

- 精简账号区入口；已有账号的启动/关闭使用同一状态按钮，关闭前保留活动考试及未知提交保护。
- 按账号配置邮件通知间隔，支持1–1440分钟，默认60分钟；调整间隔保留待汇总记录和发送去重状态。
- 自动读取课程；人工开始考试或完成验证后自动识别新试卷标签，并接续本次操作。
- 整卷读取后按10题分组、最多3组并行求解。模型先判断，仅不确定题联网复核；一题失败不丢弃其他已确定答案。
- 连续填写期间独立同步真实暂存进度，最后整卷回读；提交仍须明确授权，提供有保护的立即提交方式。
- 修复多个视频、重复播放器脚本、旧完成附件误判以及恢复队列后总面板显示过期状态等问题。
- Windows便携包包含本地后端和所需Python运行时，使用已安装的Microsoft Edge。账号和模型密钥仅在运行内存中保存。

详见[使用教程](使用教程.md)和[故障处理与回归](故障处理与回归.md)。

验证：后端427项、桌面64项通过；便携程序GUI启动、134个MCP工具发现和健康检查实测通过。详见[发布验证](发布验证-v1.9.3.md)。

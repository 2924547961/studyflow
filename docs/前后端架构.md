# 桌面与独立后台

## 进程和任务

Qt 桌面通过带随机 Bearer 配对令牌的本机回环接口连接后台。模型调用、课程题目处理、考试任务、状态和自动恢复位于后台；账号浏览器继续复用各自的工作进程。前端每两秒读取状态，显示真实阶段和回读结果。

开始任务先获得任务 ID，同一请求 ID 重试只返回原任务。账号内操作互斥，其他账号独立执行。退出桌面只断开客户端；后台任务继续。再次运行 EXE 会显示或恢复桌面，正常关闭窗口收起到托盘。要停止学习，请使用账号或课程中的停止入口。

后台仅监听 `127.0.0.1`。启动器的 `/show` 入口只显示已有桌面，需要特定请求头并拒绝网页 Origin，不返回配对令牌或账号信息。端口冲突会显示诊断提示，不终止占用端口的进程。

## 模型服务

先手动选择服务商、填写自己的地址及 API Key，读取可用模型，再手动选择并应用。列表读取只保存草稿，不应用首项。界面单独显示当前生效配置；正在运行的任务保留原模型，后续任务使用新配置。不同地址之间不复用密钥。

桌面收到的状态只有模型名称、服务商、调用统计和是否已设置密钥。密钥不写入源码、EXE、日志或配置导出；仅在当前后台会话内存保存。彻底结束后台后需要重新填写。

## 网页进度同步

播放器原生 `timeupdate`、`pause`、`playing`、`ended` 等事件将当时真实 `currentTime` 推送到后台。正常播放不再每两秒主动读取视频。回调校验页面、视频 frame、订阅标识和顺序号；旧视频或延迟事件不会覆盖当前任务。后台通过本机事件流即时推送到桌面，只更新进度控件。跨进程约每200毫秒读取工作进程内存；不访问网页、不自行累计时间。数字使用真实位置，进度条仅在两个已收到的位置之间平滑过渡。

事件超过15秒没有到达时，执行低频只读检查；暂停、异常和结束仍由原有守护流程检查。同步不 seek、不修改播放报告、不产生平台进度请求。平台自身上报有独立周期，当前实测播放器约60秒上报一次；不承诺服务端学习记录逐秒变化。任务完成以独立目录为准。

## 故障原则

只读连接失败、浏览器生命周期和提交结果未知分开处理。提交结果未知先核验原结果，不重复提交。确认成功后的旧等待状态不会触发第二次处理；新任务出现后解除去重。本人验证保留通知和二维码更新流程，其他账号继续。

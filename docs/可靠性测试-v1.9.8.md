# v1.9.8 可靠性测试范围

仅供学习用途，严禁用于刷课。故障注入使用隔离数据和浏览器页面，不向真实账号注入错误提交或验证失败。

| 场景 | 核验方式 | 必须保持的行为 |
| --- | --- | --- |
| 同一卡片多个视频及残留弹题 | 离线真实 Edge 三视频弹题、两段短视频播放 | 当前未完成视频唯一绑定，其他视频不干扰 |
| 弹题消失/完成后等待未清 | 浏览器模拟延迟结束、同任务状态回读 | 自动接续，身份不同或结果未知不解除保护 |
| 连续弹题早于桌面下一次刷新 | 桌面事件序列 | 确认上一题后继续下一题，未知题不重答 |
| 页面切换时旧采样迟到 | 桌面缓存和真实账号接续 | 不把旧媒体读请求排到新测验页面 |
| 控制线程超时及随后连续报错 | 原队列模拟、实际账号只读探测 | 仅原线程响应才恢复，不整体重启 |
| 同账号关闭/打开与恢复重叠 | 桌面并发任务测试 | 同账号动作互斥，其他账号不受阻 |
| 单账号调用慢或失败 | Bridge异步并发故障注入 | 其他账号状态及操作独立完成 |
| 浏览器原页关闭而考试新标签存活 | 标签和恢复测试 | 识别正确试卷，不重建存活浏览器 |
| 考试已交卷后切换课程 | 提交回执身份/终态测试 | 归档旧考试，当前课程不显示旧卷进度 |
| 提交点击后超时 | 原计划和完整评分回读测试 | 不重复提交，评分匹配后接续 |
| 空frames、加载中、frame脱离、网络读超时 | 有界退避故障注入 | 仅适用读取退避，验证/未知写入不绕过 |
| 人脸二维码失效、旧截图排队、SMTP结果未知 | 通知状态与附件测试 | 新图匹配本次验证，旧图不发送，未知发送不重放 |
| 教师未发布测验 | 两次观察及待补记录测试 | 保留未完成，继续其他已授权任务 |
| 模型部分结果/检索失败 | 模型响应和任务隔离测试 | 已确定结果保留，失败不扩散到其他账号 |
| 关闭桌面、配置导出、单文件运行 | 生命周期、脱敏、独立EXE启动 | 后台会话保留；导出无密钥；无需外部Python/Node/Qt路径 |

真实账号现场：账号2原视频完成后测验100分并推进新章节；账号4原第二视频弹题获正确回执，完成后进入第三视频。两者继续使用原浏览器generation。当前课程未全部完成；平台未发布的任务仍留待补。

以上是本版已覆盖场景，不等于所有未来平台变化都已验证。持续无响应、身份冲突、未知提交和本人验证保留具体原因与现场。

2026-11-01 验证结果：525项完整回归通过；追加“模型阻塞时其他账号继续、同账号重复启动拦截”并发测试通过。无真实密钥扫描命中。

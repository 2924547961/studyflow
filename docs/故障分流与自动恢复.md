# 故障分流与自动恢复

仅供学习用途，严禁用于刷课。

失败按账号、任务和故障现场隔离。只读查询、媒体播放、模型处理、写入及本人验证分别判断；其他账号继续执行。

| 失败类型 | 自动动作 | 恢复条件及边界 |
| --- | --- | --- |
| 浏览器状态查询 | 读取本地连接/关闭标志，不排队浏览器RPC；保留故障标识 | 不把控制线程异常冒充浏览器关闭 |
| 原控制线程的只读超时 | 无待提交时，在原FIFO队列做一次只读探测；新故障现场可重新探测 | 原线程响应才解锁；已关闭页只恢复本账号；真正无响应继续保留现场 |
| 只读探测迟到 | 消费已发出探测的原回执，不再排入相同探测 | 只解除对应故障；后续写入超时不会被较早只读结果掩盖 |
| 弹题提交的明确评分迟到 | 原线程结束后，核对本次题目、答案、原生点击与明确评分记录，再探测原页面 | 未知结果、旧记录、身份不符、重复回执均保留保护；不重答 |
| 提交前读取选项失败 | 原子读取选项；确认原操作结束且没有提交、完整未判分题目一致后，释放遗留审阅计划一次 | 只解除该账号同题的去重记录；场景变化、已经提交、重复失败不放行 |
| 提交后回执超时 | 核验原计划、测验身份、逐题评分；队列忙或待判分时有限只读复核 | 完整评分确认才接续；不重交、不用普通播放恢复绕开提交保护 |
| 打开/关闭/恢复账号 | 同账号生命周期动作互斥，按钮显示处理中 | 活动考试、未知提交先核验；健康账号不重建 |
| 同一卡片多个视频弹题 | 仅读取当前未完成视频的弹题，已完成或后续视频残留弹题不参与本题 | 所有读取、填写、回读绑定同一视频任务；当前视频已完成则先核对目录 |
| 弹题已消失但旧审题事件迟到 | 重新观察当前任务，媒体正常播放或平台完成时接续 | 未知结果不解除保护；恢复确认后从当前故障中清除通信错误，保留历史日志 |
| 已结束账号的延迟故障事件 | 返回“未启动”，不再尝试恢复原队列 | 不把没有浏览器当作损坏，不自动重新开始已结束任务 |
| 恢复后监听已停止 | 重启原任务的受保护监听，再接续队列；弹题转审题、验证转本人验证、完成转目录 | 不直接盲点播放；同章节的新视频或新暂停现场分别计次，同一现场去重 |
| 媒体停滞 | 核对原视频、任务标记与画面采样，走正常播放恢复 | 不拖动，不伪造完成；每段身份独立 |
| 模型或检索失败 | 保留已确定结果，只重试待处理部分 | 不把单题检索失败扩散到整组或其他账号 |
| 本人验证 | 暂停该账号，失效二维码正常刷新后发送新图 | 本人完成后重新核验，其他账号继续 |
| 教师未发布 | 留在待补清单，继续其他可用任务 | 不记为完成，等待平台发布 |

原操作尚未结束或评分未返回时，后台保留只读跟进；收到明确结果再接续。人工暂停的账号不自动恢复，未知提交不重新执行。

恢复结果显示原始故障类型、正在执行的动作以及成功/待处理结果。历史错误保留；新状态以实际回读为准。此表描述已实现流程和保护条件，不承诺未来平台变化均可自动处理。

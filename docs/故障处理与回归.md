# 故障处理与回归范围

仅供学习用途，严禁用于刷课。本页记录可复现故障和处理规则，不承诺覆盖所有环境或未来平台改版。

| 场景 | 处理方式 | 验证 |
| --- | --- | --- |
| 修改邮件通知间隔 | 每账号1–1440分钟，默认60；保留未汇总窗口和发送去重状态，清除账号时取消提醒计时器 | 窗口重排、间隔校验及通知回归 |
| 已有浏览器，再启动账号或课程 | 复用当前账号的隔离 worker；相同课程队列复用，已暂停队列接续，冲突队列保留并给出明确结果 | 路由、队列及实际账号复用检查 |
| 添加账号与启动入口重复 | 添加账号只负责录入/登录；已有账号使用同一个启动/关闭按钮，按钮依据实际浏览器状态切换 | Qt交互回归、关闭保护测试 |
| 关闭时有活动考试、待确认提交 | 保留浏览器并返回具体保护原因；已提交或判分的考试可关闭 | 活动/暂存/未知/已提交/判分状态覆盖 |
| 手动开始考试，新标签页未被发现 | 泵送真实浏览器事件；旧试卷已结算时识别唯一的新试卷；多个新试卷继续保留歧义 | 隔离Edge中新标签页实际打开与发现 |
| 先点审阅，后本人通过验证 | 记住本次预览/审阅/作答意图；每2秒读取状态，验证解除且试卷身份匹配后只接续一次 | Qt回调、身份与验证码保护回归 |
| 连续填写时桌面不更新 | 缓存状态读取与浏览器写队列分离，兼容已有worker；按真实暂存数量刷新 | 锁并发测试、实际整卷暂存与回读 |
| 缓存答案明明可用却显示待核验 | 整卷读取时将精确验证缓存同步为作答计划，继续保留缓存撤销校验 | 缓存/指纹/回读回归 |
| 多选题题干使用“哪一项” | 保留平台多选元数据；根据模型明确的逐项理由规范化格式，不改变选项或伪造确定性 | 多选规则及格式回归 |
| 某题联网或复核失败，拖住整组答案 | 保留同组已确定的答案；只对不确定题检索和复核；未知提交只读核验 | 分组并发、失败隔离、未知结果不重放 |
| 单个知识学习卡片包含多个视频 | 逐视频任务身份、DOM顺序和完成标记识别；单段监听与脚本绑定，全部必做视频完成后继续 | 双短视频实际顺序播放及完成回归 |
| 已判对弹题重现，后台没有接续 | 成功回执后仍等待超过5秒时重新观察实际页面；新弹层复用已判对的同题答案，每次仍核对本次回执。未知结果封存，章节测验不套用重试 | 成功后未观察到running、重复弹题未知回执、账号隔离测试；实际越过775秒卡点进入下一视频 |
| 视频切换时旧时间显示“更新延迟” | 传递监听状态，分别显示题目暂停、本人验证、平台完成核验与任务切换；空媒体事件清除旧进度，迟到快照不恢复旧视频 | 真实短视频通过任务缓存传递、同时间状态变更、空事件与旧快照回归 |
| 视频还在播放，推送事件丢失 | 15秒静默后仅作只读检查；确认同一视频真实推进时重挂显示监听，单段最多两次、至少间隔30秒。不重播、不跳进度 | 事件丢失恢复、正常事件零额外读取、暂停不重挂测试 |
| 桌面重连后旧连接还在读取 | 客户端连接关闭后结束该事件流，停止它自己的缓存任务；其他账号独立推送 | 真实本机HTTP断线、多状态事件和慢账号不阻塞快账号测试 |
| 已答完，剩余时间格式未识别 | 定时提交仍保留时间识别要求；用户明确要求立即提交时，重新核验整卷、身份、过期和锁定后单次提交及确认 | 明确立即提交/过期阻止、实际考试回执 |
| 双击桌面只显示未连接预览 | 默认启动内存配对的本地后端；便携入口同时支持账号worker的MCP模式 | 源码启动、便携启动和MCP握手检查 |

## 发布验证

- 后端完整回归，包括开启隔离浏览器测试；桌面Qt交互测试。
- 隔离浏览器拦截所有网络请求，使用合成页面，不重复提交真实试卷。
- 实际考试完成过整卷暂存、回读、提交、确认及成绩读取；分数来自平台，回读一致不等于答案满分。
- 发布包用独立空白会话验证启动与MCP通信，不复制运行中的账号、密钥、Cookie或状态文件。
- 机器、网络、本人验证、平台规则变化仍可能产生新问题；出现未知提交时保留现场并先核验。
